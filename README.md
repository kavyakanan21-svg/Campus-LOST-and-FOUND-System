# Campus Lost & Found Management System

## Overview

Campus Lost & Found Management System is a simple Python-based application designed to help students report and manage lost and found items on campus.

The system allows users to report lost items, report found items, view stored items, find possible matches, and mark items as resolved.

## Features

- Report a lost item
- Report a found item
- View all reported items
- Find possible matches between lost and found items
- Mark an item as resolved
- Store item data using a JSON file
- Automatically load previously stored items when the program starts
