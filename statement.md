# Project Statement

## Problem Statement

Students can lose or find personal belongings on a college campus, but there may not always be a simple way to record and manage these items.

The Campus Lost & Found Management System provides a simple way to record lost and found items and identify possible matches based on item details.

## Scope

The project focuses on managing lost and found item records within a campus environment.

The system provides basic item reporting, viewing, matching, and resolving functionality.

## Target Users

- College students
- Faculty members
- Campus staff

## High-Level Features

1. Report Lost Item
2. Report Found Item
3. View All Items
4. Find Possible Matches
5. Claim/Resolve Item
6. Store and load item records using JSON
